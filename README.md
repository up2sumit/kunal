# Bihar STET practice tests

Landing page `index.html` links to two offline-style CBT mock tests. No server or sign-in needed.

- `aot/` – Art of Teaching, 1,231 questions (complete).
- `math/` – Mathematics, in progress: currently PDF pages 3-99 (677 questions).

Answer keys are the books' printed keys. Flagged questions carry a separate verified answer (key switch on the results page). English text is not human-reviewed.
